# BALTACTICS — концепт редизайна главной страницы

Статичная главная страница (HTML + CSS + JS, без сборки) для интернет-магазина баллистической защиты и тактического снаряжения. Контент — с действующего сайта baltactics.ru.

**Что есть:** hero-слайдер, мега-меню каталога, вкладки товаров, корзина и избранное (сохраняются в браузере), вход и регистрация (демо), поиск по товарам (Ctrl/Cmd + K), переключение тёмной и светлой темы, форма обратной связи, карта, адаптив под телефоны.

Каталог, личный кабинет и оформление заказа пока работают как заглушки.

## Структура
- `index.html`, `catalog.html` — собираются из частей в `src/` командой `python3 tools/build.py`
- `assets/js/main.js` — каталог (данные с baltactics.ru), корзина, заказ через WhatsApp/e-mail, поиск, тема
- `assets/img/products/` — фото товаров с baltactics.ru

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
